# Math Games

Kid-friendly math games for Bodhi and Kaia. Anyone with the link can play in the browser on an iPad, phone, or desktop.

**Live site:** https://rmy116.github.io/math-games/

GitHub Pages serves this static site from the `main` branch, root folder.

## Games

- **[Rocket 24](https://rmy116.github.io/math-games/24/)** — use all four numbers to make 24.
- **Target Numbers** — six numbers, reach the target, endless play. Coming soon.
