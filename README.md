# Turk's Puzzles

Standalone games. Each game has its own URL and plays in the browser on an iPad, phone, or desktop.

**Turk's Puzzles home page:** https://rmy116.github.io/math-games/ links to every game.

GitHub Pages serves this repo from the `main` branch, root folder.

## Games

- **[Rocket 24](https://rmy116.github.io/math-games/rocket-24/)** — use all four numbers to make 24.
- **[Numerate](https://rmy116.github.io/math-games/numerate/)** — combine six numbers with + − × ÷ to hit the target.
- **[State Capitals](https://rmy116.github.io/math-games/state-capitals/)** — quiz on the U.S. state capitals.
- **[Math Blast](https://rmy116.github.io/math-games/math-blast/)** — times tables and division facts.
